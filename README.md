# dwg-menu-images

Temporary image host for the Dogwood Green Jane → Flowhub menu migration (Nov 2026).

Files in `images/` are named after the Flowhub product they belong to. Flowhub's `set_images`
action downloads each raw URL once and stores its own copy, so this repo can be archived or
deleted after the migration is verified on the live menu.

Raw URL pattern:
`https://raw.githubusercontent.com/poseidonretail/dwg-menu-images/main/images/<file>`
